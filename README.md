# 🎯 Smack Attack
**Smack Attack** is an interactive browser-based game developed using JavaScript. The objective is simple: hit the randomly appearing target in a 3×3 grid, earn points, and try to achieve the highest score before the timer runs out!
This project was built to strengthen my JavaScript fundamentals through practical implementation and problem-solving.

## 🚀 Features
* 🎮 **Interactive Gameplay:** Play using a 3×3 grid of holes.
* 🎯 **Random Targets:** Targets appear at random positions to make each round more engaging.
* 📊 **Score Tracking:** Earn points by hitting the target.
* ⏱️ **Countdown Timer:** Complete the game before time runs out.
* 🔄 **Game State Management:** Control gameplay using the `gameRunning` variable.
* 🖱️ **Event Handling:** Respond to user interactions through event listeners.
* ⚡ **Dynamic Updates:** Update game elements and scores during gameplay.

## 🛠️ Technologies Used
* **JavaScript** — Game logic, DOM manipulation, event handling, random target selection, and timer management.
* **HTML5** — Page structure.
* **CSS3** — Visual styling and layout.

## 📚 JavaScript Concepts Practiced
While developing this project, I gained practical experience with:
* **DOM Manipulation:** Creating and updating webpage elements dynamically.
* **Event Listeners:** Handling user clicks and interactions.
* **Random Number Generation:** Using `Math.random()` to select target positions.
* **Timers:** Using `setInterval()` and `clearInterval()` to manage game timing.
* **Conditional Statements:** Controlling game behavior based on conditions.
* **Boolean Logic:** Using `gameRunning` to manage the game's state.
* **Functions:** Organizing gameplay logic into reusable blocks.
* **Debugging:** Identifying and fixing issues involving timers, events, and game flow.

## 🎮 How to Play
1. Open the game in your browser.
2. Start the game.
3. Watch for the target to appear in one of the nine holes.
4. Click the target to increase your score.
5. Continue playing until the countdown ends.
6. Try again to improve your score!

## 💻 How to Run Locally
1. Clone this repository:
2. Open the project folder.
3. Open `index.html` in your browser.
Alternatively, use the **Live Server** extension in Visual Studio Code to run the project locally.
